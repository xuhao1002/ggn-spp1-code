### 1.2 判定草案

- **浸润程序**：A 中经外部验证的上调基因（224 个）与下调基因（128 个），限定在 L1000 基因宇宙内。
- **连接得分**：对每个池中基因的 KO 共识特征（上调集 U、下调集 D，各约 245 个），计算与程序的**反向重叠**：
  rev = |D ∩ 程序上调| + |U ∩ 程序下调|；con = |U ∩ 程序上调| + |D ∩ 程序下调|；得分 S = rev − con（正值 = 敲除后程序被逆转）。
- **零分布**：库内全部其他基因的 KO 特征（约 1 万条）用同一程序算 S，经验单侧 P = 零分布中 ≥ 该 S 的比例；对池中被检验的基因做 BH 校正。程序基因本身如果是该库的 KO 对象，其 S 不计入零分布。
- **敲低效率检查**：被敲除基因自身必须出现在它自己 KO 特征的**下调集**里；不在（或基因不在 L1000 测量集）→ 「敲低效率未证实」。
- **通过**：BH q < 0.05 且 S > 0 且敲低效率已证实。
- **细胞系**：主判定用**跨细胞系共识**（这是紧凑库里唯一的形式）。肺腺癌系（A549、HCC515 等）的单细胞系特征只作辅助：通过 SigCom API 取同一基因在肺腺癌系的特征，报告方向是否一致，不参与判定。
- **三态**：通过 / 未通过 / 无法检验（基因不在库里）。无法检验不算通过。

## 2. 间接路径（转录因子 → 可成药下游效应分子）

- **适用范围**：A 中经验证的上调基因里，DGIdb 无抑制类药物（并集 342 个，预设 352 内 183 个），且在调控资源中作为 TF 有 ≥ 5 个靶基因。
- **调控资源**：
  - CollecTRI（Müller-Dott 等 2023；经 `decoupler` 2.2.0 获取，装在 ggn_target；约 4.3 万条带正负号的 TF-靶基因关系，无置信度分层；用时记录下载日期和版本）；
  - DoRothEA 仅取高置信度 A、B 级，作为交叉印证；
  - 一条关系计入的条件：出现在 CollecTRI，或 DoRothEA 的 A/B 级，且符号一致。
- **效应分子**：TF 的靶基因满足全部条件：
  1. 在 A 中 FDR < 0.05，且方向 = TF 的方向 × 调控符号（TF 上调 + 激活 → 靶基因上调；抑制 → 靶基因下调）；
  2. 通过来源过滤；
  3. **独立通过第 3、4、5 层**（用本草案 1 的标准补完第 3 层后）；
  4. 第 1 层的外部验证不再作为条件（因为它的支持证据来自 TF 的验证）——请你确认这一点。
- **额外支持**：对每个 TF 用 decoupler 的 ULM 在每个伪批量样本上估计 TF 活性，做同一患者配对检验（以样本为单位，BH 校正），只报告，不判定。
- **输出**：每个 TF → 效应分子列表 → 各层通过状态；只有当效应分子本身可成药且通过第 3–5 层，才视为该 TF 的可成药入口。

## 3. 微环境分析

### 3.1 配对伪批量
- **细胞群**：T/NK（含增殖）、髓系（巨噬、单核、cDC、pDC、中性粒、增殖髓系）、B/浆、成纤维、血管内皮、平滑肌/周细胞（淋巴管内皮和肥大细胞数量少，只作敏感性）。每个群各自做 22 对伪批量，设计 `~ 患者 + 病变类型`，LUAD 对前体，pydeseq2，FDR < 0.05；每侧至少 50 个细胞，不够的患者排除并列出。
- **基因过滤**：每群与上皮的计数阈值同第一步（计数 ≥10 的样本数 ≥ 总数 1/3 且总计数 ≥ 50）。
- **同一状态内的敏感性**：对髓系与 T 群取主要亚群（巨噬、T 细胞）单独再做一次，区分「细胞组成变化」和「状态内改变」。

### 3.2 来源过滤反向执行
对每个群 L，沿用第一步的「谱系 × 样本」中位表达表：
- **疑似上皮来源**：上皮中位表达 ÷ 该群中位表达 > 5（即该群/上皮 < 0.2）→ 标记并剔除；
- **环境 RNA**：除第 1 点外，剔除固定名单（SFTPA1/2、SFTPB、SFTPC、SFTPD、NAPSA、SCGB1A1、SCGB3A1、SCGB3A2、SLPI、WFDC2、MUC1、LAMP3、AGER）；再加数据驱动：该基因在群 L 的伪批量表达与同一伪批量的「SFTPC+SFTPB+SFTPA1 平均表达」的 Spearman 相关 > 0.6，标记「环境 RNA 相关」，剔除；
- 对 GSE164789 同法计算比值并「救回」，规则同第一步。

### 3.3 配体–受体分析
- **工具**：LIANA+（`liana` 1.10.0，装在 ggn_target；资源 `consensus`，方法 `rank_aggregate`）。
- **方向**：发送方 = 上皮（A 中经验证的上调基因作配体），接收方 = 各微环境群；也报告微环境配体 → 上皮受体。
- **做法**：每个样本（至少 20 个该群细胞）分别运行；一对相互作用 = 配体在发送方表达、受体在接收方表达、且二者在 A 或第 3.1 的差异分析里**同向上调**；每个相互作用取各样本 magnitude_rank 的患者配对差（LUAD 减前体）。
- **验证**：在 GSE164789 按同一规则运行，用病灶单位（IAC vs AIS+MIA）检验方向；规则同第 1 层：验证集内单侧 P 做 BH，q < 0.05 且同向。
- **通过**（作为微环境靶点候选）：配体或受体基因满足第 3.4 的各层。

### 3.4 第 3、4、5 层对非上皮细胞怎么办
- **第 3 层不适用**：DepMap 和 L1000 主要是肿瘤上皮细胞系，不能代表巨噬、成纤维、内皮。处理：标记「第 3 层不适用」，不计通过也不计否决；改为**人工文献核查**（每个候选至少记录 1 篇该细胞类型中的功能证据，记来源，不进自动判定）。微环境靶点的成功标准因此写成「通过第 1、4、5 层且来源过滤、配体受体验证」，并在文中明确标注缺第 3 层。
- **第 4 层**：沿用同一套队列和 Cox；因为批量转录组里微环境基因反映细胞组成，加一个协变量：该细胞群的标志基因平均 z 分数（巨噬、成纤维等），要求通过后基因效应在调整后仍满足 q < 0.05。
- **第 5 层**：沿用 DGIdb 与 HPA；**GTEx 全血和骨髓的高表达否决对免疫细胞靶点不适用**（几乎所有免疫基因都在血里高表达），改为只标注「免疫毒性风险」，心、肝、肾仍按 ≥50 TPM 否决。请你确认这一例外。
