# 磨玻璃结节阻断靶点筛选：研究设计与数据清单

Oct 8, 2026 · @DuDu

本研究只用公开数据，筛选驱动磨玻璃结节（AIS/MIA）向浸润性腺癌进展、并且适合长期用药的干预靶点。第一步的产出是一张靶点排序表，每个靶点附五层独立证据。

## 研究目标与预设分析方案

以下目标和判定标准于 Oct 8, 2026 定稿，在看到任何分析结果之前确定；后续分析严格按此执行，偏离之处须在论文中注明。

**核心问题**：在磨玻璃结节从惰性病灶（AAH/AIS/MIA）走向浸润性腺癌的过程中，哪些基因驱动了这一转变，并且适合作为长期、低毒的药物干预靶点？

**假设**：存在一组在前体病变中已经出现、在浸润癌中进一步升高的上皮内在程序；其上游调控因子或效应分子能被现有药物抑制，且这些药物在正常组织中的毒性可以接受。

**三项设计决定**

| 决定 | 选择 | 理由 |
| --- | --- | --- |
| 主要比较 | 同一患者内前体病变对浸润癌的配对比较；正常→AAH→AIS/MIA→浸润癌的阶段趋势作为次要分析 | Peng 数据中多数患者同时有前体病变和浸润癌，配对能排除个体差异 |
| 靶点来源 | 上皮为主，微环境为辅 | 主线叙事清楚；与 Peng 2026 的抗炎（微环境）方向拉开差异 |
| 靶点定义 | 可成药蛋白优先 | 最终排序只纳入酶、受体、膜蛋白等可成药蛋白；转录因子等难成药的上游驱动因子通过其可成药的下游效应分子间接纳入 |

**各层入选标准**

1. 候选池：样本层面检验 FDR < 0.05；在 Peng 数据中显著，且在至少 1 个独立单细胞数据集（GSE164789 或 GSE189357）中方向一致。
2. 驱动性：位于调控网络上游，虚拟敲除后细胞状态向前体病变方向偏移。仅作预测，不单独构成入选理由。
3. 真实扰动：在 DepMap 或公开敲低/敲除数据中有支持证据。
4. 临床相关：在至少 2 个独立 I 期队列中与复发或生存相关，方向一致。
5. 安全与可成药：有已上市或在研药物；在心、肝、肾、骨髓等正常组织中不高表达。

**成功标准**：至少 1 个靶点通过全部五层。若第 1 层结果在独立数据集中无法重复，回头重新评估方向，不降低标准。

**不在本文范围内**：STAS（待潘良睿团队提供 TCGA/CPTAC 标签后另立一篇）、免疫治疗反应预测、EGFR 亚型比较。

## 研究问题与定位

核心问题：哪些基因或调控因子驱动磨玻璃结节从惰性的 AIS/MIA 走向浸润，而且适合作为长期、低毒的药物干预靶点？

**临床空白**：肺腺癌靶向药只用于确诊的肺癌；大量磨玻璃结节患者只能随访观察，没有任何获批的药物干预。已有的尝试效果都不理想：

- PD-1 抑制剂：信迪利单抗治疗高危磨玻璃结节、替雷利珠单抗治疗多发磨玻璃结节的 II 期试验，病灶缓解有限。
- 中药：多中心随机对照试验仍在进行，缺乏机制依据。

**为什么第一步只做靶点**：靶点排序表本身就能成文，工作量可控；药物筛选（CMap/LINCS）放在第二步，或作为本文最后一部分。

**与肺癌靶向药的根本区别**：肺癌靶向药追求短期高强度杀伤；结节阻断要求长期、低毒、最好口服，目标是让病灶停在惰性状态，而不是消灭它。这决定了靶点的筛选标准不同，也是本文的核心论点。

## 靶点筛选：五层证据

候选靶点逐层过滤，每层用独立的数据回答一个问题；最终产出靶点 × 证据矩阵（前 10 个），再挑 1–3 个最强的深入展开。

| 层 | 回答的问题 | 数据 | 方法 | 证据性质 |
| --- | --- | --- | --- | --- |
| 1. 候选池 | 同一患者体内，哪些基因和程序在浸润癌中高于前体病变（AAH/AIS/MIA）？ | Peng 2026 人类前体病变数据、GSE189357、Chen 2025 空间数据 | 同一患者配对的伪批量差异分析（样本层面，设计 \~ 患者 + 病变类型），上皮为主、微环境为辅；阶段趋势为次要分析；与已发表的进展程序交叉印证 | 观察 |
| 2. 驱动性 | 谁是上游调控因子，敲掉后细胞是否"退回" AIS 样状态？ | 同上 | SCENIC 调控网络；CellOracle 虚拟敲除 | 计算预测，正文明确标注 |
| 3. 真实扰动 | 真实敲低/敲除后，浸润程序是否下调？ | LINCS L1000 敲低谱、GEO 肺癌细胞系敲除数据、DepMap | 程序逆转评分（看表达特征是否逆转，不看细胞是否死亡） | 真实实验数据 |
| 4. 临床相关 | 在独立队列中是否随浸润升高、是否与 I 期复发相关？ | GSE102511、GSE166720、GSE193725；TCGA、GSE31210、GSE50081、GSE72094 | 阶段比较；多队列 Cox 加 meta 分析 | 观察，独立队列 |
| 5. 可成药与长期安全 | 有没有现成药物？能否长期服用？ | DGIdb、ChEMBL、Open Targets、GTEx、HPA | 已上市或在研药物；正常组织表达，尤其肝、肾、心、骨髓 | 数据库证据 |

第 5 层是阻断研究特有的：结节患者无症状、用药周期以年计，正常组织高表达的靶点即使驱动性强也要降级。

## 竞争研究与差异化

PubMed 检索（2026-10-08）未发现针对前体病变或磨玻璃结节的系统靶点筛选或计算药物重定位研究；相关工作要么只研究单个靶点，要么只做预后签名。

| 研究 | 做了什么 | 没做什么（我们的切入点） |
| --- | --- | --- |
| [Peng 2026, Cancer Cell](https://pubmed.ncbi.nlm.nih.gov/41202811/) | 前体病变进展中肺泡祖细胞与促炎生态位共演化；小鼠中抗炎单用或联合免疫治疗减少祖细胞 | 没有系统排序靶点，没有评估可成药性和长期安全性 |
| [Zhang 2025, Cancer Cell](https://pubmed.ncbi.nlm.nih.gov/40345189/) | 提出 TIM-3 作为癌前阻断靶点 | 单一免疫靶点，未覆盖上皮内在驱动因子 |
| [Deng 2026, Mol Cancer Ther](https://pubmed.ncbi.nlm.nih.gov/41024580/) | 克拉霉素在 KRAS 小鼠中预防前体病变和癌变 | 凭经验选药，不是数据驱动的筛选；模型为 KRAS 驱动，与国内 EGFR 为主的结节人群不同 |
| [J Thorac Dis 2026](https://pubmed.ncbi.nlm.nih.gov/42583106/) | 用 GSE189357（9 例）的 AIS→IAC 轨迹构建早期浸润签名，预测 I 期生存 | 只做预后签名，发现集小，没有扰动验证和成药性评估 |
| PD-1 抑制剂治疗磨玻璃结节的 II 期试验（[STTT 2024](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11026465/)；CII 2025） | 信迪利单抗、替雷利珠单抗 | 病灶缓解有限，提示需要免疫治疗以外的靶点 |

**差异化**：一是用目前最大的开放前体病变数据集；二是五层独立证据，其中第 3 层是真实扰动数据；三是把长期用药安全性作为硬性筛选标准。

## 主要风险与对策

最大的风险是验证层和问题不完全对口：现有扰动数据来自癌细胞系，而我们要阻断的是早期病灶的转化。

| 风险 | 对策 |
| --- | --- |
| DepMap 测的是癌细胞存活依赖，不是"阻止浸润" | 第 3 层以程序逆转评分为主，DepMap 只作辅助；明确写入局限性 |
| LINCS 没有肺泡上皮祖细胞系，最接近的是 A549 等肺癌细胞系 | 同时使用免疫细胞系扰动谱覆盖生态位靶点；用 Peng 2026 小鼠数据做跨物种检验 |
| Peng 2026 中 MIA 只有 4 个病灶，阶段间样本不均衡 | 以 AAH/AIS 对浸润癌作为主比较；用 GSE189357 和三个 bulk 队列补足 MIA |
| 筛出的靶点与 Peng 2026 的抗炎方向重合 | 重合本身是佐证；新颖性落在具体靶点排序和可成药性评估上 |
| 虚拟敲除被审稿人质疑 | 正文标注为预测；每个结论都要有第 3 或第 4 层的真实数据支撑 |
| Peng 团队后续发表同类工作 | 尽快完成第 1–2 层，先投预印本占位 |

## 质量控制与统计规范

下面每一条都对应参考文章（npj Digit Med 2025）里出现过的问题，写作和投稿前逐条核对。

| 参考文章的问题 | 本研究的做法 |
| --- | --- |
| 用细胞数比例条形图声称"富集"，属于假重复 | 所有组成差异以样本为单位检验，图中画每个样本的点 |
| 免疫治疗反应只用 TIDE 预测 | 用真实免疫治疗队列验证；TIDE 最多作补充 |
| 同一类细胞的亚群数在不同图里对不上 | 建立一张亚群命名总表，所有图和正文都从这张表取名 |
| 讨论与结果方向相反 | 定稿前逐句核对每个结论对应的图号和方向 |
| 图号、面板标签错误 | 图注与正文引用用脚本自动核对 |
| 分级信息来源未交代 | 每个样本的阶段和分级来源写入补充表 |
| 方法里写了但结果里没有（SCENIC） | 方法只写实际用到并展示的分析 |
| 引用文献与内容不对口 | 每条引用核对原文 |
| 代码"合理请求后提供" | 代码上传 GitHub，投稿时公开 |

**其他统计原则**

- 多重比较一律做 FDR 校正。
- 生存分析的最佳截断值容易过拟合：发现集定截断值，验证集沿用，或直接使用连续变量。
- 评分在一个队列里构建，在其他队列里验证，不在同一数据上既训练又评估。
- 用单个数据集重复主要结论，证明不是批次效应造成的。

## 进展与方向调整（2026-10-08）

第 1 层已完成并通过外部验证，但第 3–5 层跑完后，预设候选池中没有任何基因同时通过这三层；尚未有靶点通过全部五层。以下记录结果、原因和已确定的后续方向，入选标准一律不放宽。

**已完成**

| 步骤 | 结果 |
| --- | --- |
| 单核数据质控与注释 | 75 个样本、23 名患者，清理后保留 700,199 个细胞；上皮 194,554 个 |
| 第 1 层：配对伪批量（AT2 谱系，22 对） | FDR < 0.05 的基因 6,676 个；通过来源过滤和外部验证（GSE164789 或 GSE189357，单侧 BH q < 0.05 且同向）的 352 个，上调 224、下调 128 |
| 第 3 层：DepMap（上调 224 个） | 通过 29 个；常见必需基因按长期毒性风险否决 |
| 第 4 层：7 个 I 期队列 | 通过 59 个 |
| 第 5 层：可成药与安全 | 通过 17 个 |
| 第 3–5 层同时通过 | 0 个（预设 352 内）；事后追加的 AT2 谱系验证版中只有 TTK 1 个 |

**预设之外的处理（如实标注）**

- 验证集原定使用全部上皮，与主要分析的 AT2 谱系不一致；看到结果后追加了 AT2 谱系版验证，作为敏感性分析并列报告，不替代预设结果。
- TTK 只来自事后追加的那一版，且它是有丝分裂检查点激酶，与长期低毒的目标冲突，不作为结论，只在文中作为附带观察。
- 第 1 层的优先级分层（效应量、状态内分析同向）是看到差异基因数之后加的，只用于排序，不作入选条件。

**原因分析**：第 3 层（细胞系存活依赖）和第 4 层（I 期预后）本质上都偏向增殖相关基因，而第 5 层的长期安全要求会排除增殖和必需基因，三层之间存在结构性矛盾。驱动浸润、但与增殖无关的基因，在第 3、4 层拿不到证据。这本身是一个发现：前体病变走向浸润的上皮转录变化，主要由增殖和去分化构成。

**后续方向（均为研究设计中已写明、尚未完成的部分）**

1. 补完第 3 层：设计写的是「DepMap 或公开敲低/敲除数据」，目前只用了 DepMap。补充 LINCS L1000 的基因敲低特征，检验敲低后浸润程序是否被逆转，对象是待补充池的 294 个基因。
2. 间接路径：转录因子等难成药的候选，通过其可成药的下游效应分子纳入。
3. 微环境分析：按「上皮为主、微环境为辅」开展，判定标准先定再跑。
4. 探索性分析（不参与判定）：第 4 层 Cox 模型加入增殖评分作为协变量，找出预后作用独立于增殖的候选。
5. 第 2 层（虚拟敲除，仅作预测）在以上完成后，对留下的候选再跑。

**补充分析结果（2026-10-08 22:30，第一阶段定稿）**

| 分析 | 结果 |
| --- | --- |
| LINCS 敲除特征（补完第 3 层） | 待补充池 294 个中 92 个有数据；非增殖程序逆转 0 个；阳性对照（TOP2A、CDK1 逆转增殖程序）成立 |
| 间接路径 | 预设 352 内 8 个转录因子，符合条件的效应分子 0 个 |
| 第 4 层加增殖评分协变量（探索性） | 通过数 59 → 1，预后信号几乎全部来自增殖 |
| 微环境第 1 层 | T/NK 475、髓系 926、成纤维 372、内皮 29、平滑肌/周细胞 5、B/浆 0 个通过外部验证 |
| 微环境第 1、4、5 层 | 第 5 层修正后 6 个基因；核查后可信的只有 LOXL2、CD276、SPHK1、MMP14，且临床或安全证据均弱 |
| 第 5 层修正 | 去掉 cleavage 类作用，A 级须有 ChEMBL/TTD 抑制机制记录；上皮通过数不变，A 级大量降为 B 级 |

**最稳健的发现：SPP1+ 髓系细胞扩增。** 髓系中 LUAD 比前体高（log2FC +3.57，FDR 3.7×10⁻⁹），GSE164789 与 GSE189357 均通过，第 4 层通过（HR 1.31，q = 0.019），与 Zheng 2025（Mol Cancer）的功能实验一致。但第 5 层因肾脏高表达（GTEx 肾髓质 3,689 TPM，HPA 肾近端小管 High）否决。CD44、PTGER4 在本研究中不成立；TREM2、CXCL9 升高但无临床支持。

**第一阶段结论**：按预设标准，没有靶点通过全部五层。前体病变走向浸润的上皮程序以增殖为主；微环境中最稳健的特征是 SPP1+ 髓系细胞扩增，而直接抑制 SPP1 存在肾脏安全隐患。完整汇总见电脑上的 docs/第一阶段结果汇总.md。

**重要局限（待核实）**：Peng 2026 的前驱病灶可能多为切除标本中同步检出，而非 CT 发现的磨玻璃结节；逐病灶影像与分期须从其 Table S1 确认。是否开展第二阶段（候选方向：SPP1+ 髓系状态的上游诱导信号，以同一病灶内部比较为主）待阅读文献后决定，若开展须单独预设标准。
