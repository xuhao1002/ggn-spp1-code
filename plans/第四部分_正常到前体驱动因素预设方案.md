# 第四部分：「正常 → 前体」驱动因素与分步检验预设方案（草案，待用户确认；确认前不运行任何分析）

起草日期 2026-10-09。结果一律存放在 `results/40_drivers/` 起，脚本编号 40 起，与前三部分分开。

## 0. 定位与诚实声明

- **本方案是在看到第二阶段结果之后起草的**，相对第二阶段属于**事后追加**，必须在论文中如此标注，不得呈现为第二阶段的原始预设。
- 但**本方案内部的全部阈值、检验与判定规则，在运行本部分任何分析之前写定**；凡沿用第二阶段已固定的数值，一律直接引用、不重新计算（见第 1.2 节）。
- 起草动因（如实记录）：第二阶段的两项主要检验（AT2 谱系 IL1R1、IL1B+ 巨噬细胞比例）为阴性，阳性结果集中在 KAC 比例、CAS 样上皮比例与 CD47；文章主线因此调整为「正常 → 前体」。本部分要回答两个随之产生的问题：**(a) 这些阳性变化出现在哪一步（正常 → AAH，还是正常 → AIS/MIA）；(b) 它们是病变特异的，还是肺泡损伤修复状态本身就有的。**
- **本部分不设立新的「靶点通过」成功标准**，不产生新的入选资格；产出是分步定位结果、一份「阶段特异且非修复态共有」的候选分级表，以及配体–受体线索。第二阶段的 32 个基因×群（`results/20_stage2/stage2_pass_all.tsv`，31 个 AT2L + 1 个髓系 CD1A）的入选状态不因本部分改变。

### 0.1 一条贯穿全部分的原则（新增，须写入论文方法）

本研究只能界定「哪些候选在人体数据中满足阶段特异性与表达安全性」。**干预方向的正负（抑制有益还是有害）不可由表达高低推断**，须由分阶段扰动实验决定。依据：Su 2025（Nat Commun 2025;16:2414，PMID 40069142）中 PCSK9 消融**促进**起始、增强 ER 应激**抑制**进展，方向与表达差异相反。本部分所有候选表均附此声明。

### 1.3 统计

- **比例类指标**：每个伪批量一个值，配对 Wilcoxon 符号秩，**单侧**（方向与第二阶段的预期一致：前体更高）。8 对时单侧最小可能 P = 1/256 ≈ 0.0039，16 对时远小于此，均可达到显著。
- **表达类指标**：pydeseq2，设计 `~ patient + condition`，基因过滤同第二阶段；**但 AAH 组 8 对仅用于预设的上述单个基因**，报告 log2FC、未校正 P、以及在该次运行全基因组结果中的 FDR。另并行报告在 log1p CPM 上的配对 Wilcoxon 单侧 P 作为稳健替代（8 对时 DESeq2 的方差估计不稳）。
- **多重检验**：**按指标分家族，每个指标在两步（AAH、AIS/MIA）上共 2 个检验，Holm 校正**；同时报告未校正 P。不跨指标合并家族。ssGSEA 评分不进入任何 Holm 家族。
- **「支持」的定义**：方向一致、单侧 P<0.05、且该指标家族内 Holm 校正后 P<0.05。
- **判定**：**只报告，不用于任何靶点入选**。
- **8 对不做全基因组发现**：AAH 组**不产出新的候选基因**，不做 FDR 筛选后的候选清单。理由：8 对的检验力不足以支撑全基因组 FDR，且这样做等于用低检验力数据扩充候选池。此条为硬性限制，不得在运行中放宽。

## 2. 分析 B：状态匹配比较（病灶 KAC vs 同患者正常肺 KAC）

### 2.1 问题与设计理由

KAC 本身是肺泡损伤修复状态，正常肺中也存在。「前体 vs 正常」的组织水平比较无法区分**病变状态**与**修复状态**；只在病灶 KAC 中升高、而正常肺 KAC 中不升高的基因，才可能是阶段特异的。该比较同时直接服务于安全性评估（KAC 参与正常肺泡修复，抑制修复态共有的分子存在风险）。

### 2.2 定义（在看结果前写定）

- **KAC 细胞**：AT2 谱系细胞中 KAC 得分 > **0.1196**（第 1.2 节的固定阈值，不重算）。
- **重要的构造性说明（须写进方法）**：该阈值由 Normal 细胞自身的第 90 百分位定义，故**正常侧 KAC 样细胞按构造约占正常 AT2 谱系细胞的 10%**。因此本分析**不是比例比较**（比例比较已在分析 A），而是「病灶中高 KAC 得分细胞」与「正常肺中高 KAC 得分细胞」之间的**表达差异比较**。
- **伪批量单位**：患者 × 组织（前体 = AAH/AIS/MIA 合并；Normal）。每侧 KAC 细胞 **≥50 个**，不足的患者排除并列出。
- **对照分析（必做）**：同一设计下的 **AT2L-other**（KAC 得分 ≤ 阈值的 AT2 谱系细胞）病灶 vs 正常配对伪批量。用于说明分析 B 的差异不是全体上皮的普遍差异。

### 2.3 运行前的只读核查（由 Code 先做，不做检验）

报告以下数字，再决定是否运行：
1. 每名患者前体侧与 Normal 侧的 KAC 细胞数，满足两侧 ≥50 的**可配对数**；
2. 同上对 AT2L-other 的可配对数；
3. **规则：可配对数 < 8 对 → 该项标「无法进行」，不下调门槛、不改阈值。** 若 KAC 可配对数不足 8 而 AT2L-other 足够，只报告后者并说明前者无法进行。

### 2.4 候选判定

一个基因进入「阶段特异候选」须同时满足：
1. 病灶 KAC > 正常 KAC，FDR<0.05；
2. 不属于第二阶段增殖基因集（196 个，`prolif_genes.prolif_set_stage2()`）；
3. 通过来源过滤（上皮规则，沿用第一阶段表 `results/04_source_filter/`）。

并按与对照的关系分级（只分级，不改入选）：
- **梯队 S（阶段特异）**：满足上述三条，且在 AT2L-other 的同一比较中**不显著**（FDR≥0.05）或效应量明显更小（|log2FC| 差值 ≥0.5）；
- **梯队 R（修复态共有）**：满足上述三条，但在 AT2L-other 中同样显著且效应量相近 → 标记「修复相关风险」。

1. **新增标记项**：候选若在正常肺 KAC（修复态）中同样高表达或同样升高（分析 B 的梯队 R），在最终表中标「修复相关风险」。**不自动否决**，但必须标出，并在讨论中说明长期抑制可能影响肺泡修复。

3. 第 5 层其余规则沿用第一阶段修正后版本（cleavage 修正、A 级须 ChEMBL/TTD 抑制机制记录、免疫来源靶点的血液/骨髓规则、心肝肾 GTEx ≥50 TPM 或 HPA High 否决）。
